# ひだまりの家 / コードの地図

HTML・CSS・JavaScript のしくみを、家と街にたとえて説明する2枚組の読みもの。日本語と英語を切り替えられます。

| ページ | 内容 |
| --- | --- |
| [`index.html`](index.html) | **ひだまりの家** — 1軒の家を歩きながら、HTMLのタグ、CSSの grid・flex・float、JavaScriptの役割を見ていきます |
| [`map/index.html`](map/index.html) | **コードの地図** — 家を出て街へ。コードの種類、言語の選び方、どの言語にも共通する部品、表と裏のしくみ |

## ひだまりの家でできること

画面右下の3つのスイッチで、ページそのものを実験台にできます。

- **English / 日本語** — `<html lang>` を書き換えるだけで表示が入れ替わります
- **間取り図 ON** — ページを組み立てているタグの名前が、すべて青焼きの図面として浮かび上がります
- **CSS OFF** — 内装（`<style>`）をまるごと無効にして、骨組みだけの姿にします。それでもスイッチが動くのは、動かしているのが JavaScript だからです

廊下では `justify-content` の値をボタンで切り替えて、flex の並び方をその場で確かめられます。

## コードの地図でできること

- 作りたいもの（サイト・アプリ・ゲーム・AI・データ）で言語を絞り込めます
- 変数・リスト・条件・繰り返し・関数を、Python / JavaScript / Luau の3つで並べて見比べられます

## 公開

静的なHTMLだけで、ビルドは不要です。GitHub Pages にそのまま載せられます。

リポジトリの **Settings → Pages** を開き、Source に `Deploy from a branch`、Branch に `main` / `/ (root)` を選べば公開されます。

手元で見るときは、`index.html` をブラウザにドラッグするだけで動きます。サーバーは要りません。ページ間のリンクもファイル名まで書いてあるので、`file://` のまま行き来できます。

Python が入っている環境なら、このフォルダで簡易サーバーを立ててもかまいません。

```bash
python -m http.server 8000
```

## つくり

外部のライブラリやフレームワークは使っていません。読み込んでいるのは Google Fonts の字体だけです。

- 1ページ1ファイル。HTML・CSS・JavaScript がすべてその中に入っています
- 日英の切り替えは、同じ場所に `<span lang="ja">` と `<span lang="en">` を並べ、使わないほうをCSSの1行で隠す方式
- 配色は `:root` のカスタムプロパティにまとめてあり、端末が暗い表示のときは自動で夜の色に変わります。ひだまりの家では、屋根に映る家の写真も昼と夜で入れ替わります
- コードの中のコメントは、そのまま解説として読めるように日本語で書いてあります
