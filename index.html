リビングLiving room

家でいちばん広い部屋です。main タグの中には、このページの主役になる内容を置きます。ここでは main が家の居住スペース全体、その中の section がひとつひとつの部屋にあたります。 The largest room in the house. Inside the main tag sits everything that matters most on the page. Here, main is the whole living space, and each section is a single room.

右下の「間取り図 ON」を押すと、この家を作っているタグの名前が見えるようになります。 Press “Blueprint ON” at the bottom right, and the name of every tag in this house will appear.

p はメモ用紙1枚。a は別の部屋へ通じるドア。div は中身をまとめる無地の箱です。 p is a sheet of notepaper. a is a door to another room. div is a plain box that simply holds things together.

廊下（flex）Hallway (flex)

flex は、引き出しの仕切り板のように、箱を一列に並べる仕組みです。下のボタンを押して、並び方を変えてみましょう。 Flex works like the dividers in a drawer, setting boxes out in a single row. Press the buttons below and watch how they arrange themselves.

いまの指示：Current rule: .hall { display: flex; justify-content: flex-start; }

この家では、玄関のドア、キッチンの棚、この廊下、設備室のカード、フッター、右下のスイッチが flex で並んでいます。 In this house, flex lines up the doors at the entrance, the kitchen shelf, this hallway, the cards in the utility room, the footer and the switches at the bottom right.

書斎Study

本Book

左の「本」は float: left で左に寄せています。文章が本の右側に回り込んでいるのがわかりますか。 The book on the left has been pushed aside with float: left, and the text wraps round it. Can you see it?

今のウェブ制作では、横並びや均等配置は flex や grid を使うのが主流です。float は、写真のまわりに文章を回り込ませたいときに使います。 Today, lining things up in a row or spacing them evenly is mostly left to flex and grid. Float is kept for wrapping text around a picture.

寝室Bedroom

この部屋の表札は id="bedroom" です。id は家の中で1つだけの名前で、玄関のドア（リンク）がここへ案内してくれます。 This room’s nameplate is id="bedroom". An id is a name that appears only once in the house, and the doors (links) at the entrance lead you here.

ゆっくり休んだら、玄関に戻ることもできます。 When you have rested, you may return to the entrance.

設備室Utility room

この家は、3つの材料でできています。 This house is made of three materials.

HTML

骨組みThe frame

どこに何があるかを決めます。壁、部屋、ドア、文章。Decides what is where: walls, rooms, doors and words.

書く場所：Written in: <body>

CSS

内装The interior

見た目を決めます。Decides how it looks.

  • 屋根の形と色The shape and colour of the roof
  • ドアの丸みThe rounded doors
  • 部屋の配置（grid）The layout of the rooms (grid)
  • 箱の横並び（flex）Rows of boxes (flex)

書く場所：Written in: <style>

JavaScript

電気とスイッチThe wiring and switches

押したら動く仕組みを作ります。Makes things happen when you press them.

  • 右下の3つのスイッチThe three switches at the bottom right
  • 廊下の並び替えボタンThe hallway buttons

書く場所：Written in: <script>

試してみましょう。右下の「CSS OFF」を押すと、内装が消えて骨組みだけの家になります。間取り図が見えなくなるのは、見た目を決めているのが CSS だからです。それでもスイッチが動くのは、動かしているのが JavaScript だからです。 Do try it. Press “CSS OFF” at the bottom right, and the interior vanishes, leaving only the frame. The blueprint disappears too, because how things look is CSS’s work. Yet the switches still work, because they are JavaScript’s.
