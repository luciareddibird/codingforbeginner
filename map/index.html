コードの地図A Map of Code

家（ウェブサイト）を出て、街を歩いてみよう。 Step out of the house, and walk into the town.

コードは、コンピュータに渡す「手順書」です。片付けで「冬服は手前へ、夏服は奥へ」と決めるのと、よく似ています。 Code is a set of instructions handed to the computer. It is much like deciding, when tidying, that “winter clothes go to the front, summer clothes to the back”.

このページでは、コードにどんな種類があるのか、どう組み立てるのかを、片付けにたとえて見ていきます。 This page looks at the kinds of code there are, and how they are put together, all in terms of tidying.

1書くものは4種類Four kinds of writing

「コード」といっても、書くものは大きく4つに分かれます。 “Code” covers a good deal, but what you write falls into four broad kinds.

ラベルLabels　HTML

「これは見出し」「これは段落」と、名前を付けます。 Gives names: “this is a heading”, “this is a paragraph”.

片付けでいうと　箱にラベルを貼る In tidying terms: sticking labels on boxes

見た目Looks　CSS

色や大きさ、並べ方を決めます。 Decides the colours, the sizes and the arrangement.

片付けでいうと　部屋のインテリア In tidying terms: the decoration of a room

手順Steps　JavaScript, Python …

「こうなったら、こうする」という動きを書きます。 Writes down what happens: “when this occurs, do that”.

片付けでいうと　「冬服は手前へ」というルール In tidying terms: a rule such as “winter clothes go to the front”

質問Questions　SQL

データの倉庫に「○○を全部持ってきて」と頼みます。 Asks the warehouse of data: “bring me every such-and-such”.

片付けでいうと　倉庫番への注文書 In tidying terms: an order slip for the storekeeper

一般に「プログラミング言語」と呼ばれるのは、おもに3つ目の「手順」の仲間です。HTMLとCSSは、ラベルと見た目を書く言葉です。 What people usually call a “programming language” is mostly the third kind, steps. HTML and CSS are languages for labels and looks.

2作りたいもので選ぶChoose by what you wish to make

日本語と英語のように、言語が違っても「できること」は似ています。得意な場所が違うだけです。作りたいものを選ぶと、その街の言葉が出ます。 Languages differ, much as Japanese and English do, yet they can do broadly similar things; each is simply at home in a different place. Pick what you wish to make, and the languages of that town will appear.

3どの言語にも共通する部品Parts every language shares

言語が違っても、部品の考え方は同じです。同じ内容を3つの言語で書き比べます。言語を選んでみましょう。 The ideas are the same whatever the language. Here is one thing written in three of them. Choose one.

Python：ブロックの区切りは「字下げ」。メモ書きは # ではじめます。AI・自動化・データ分析で使われます。 Python: blocks are marked out by indentation, and notes begin with #. Used for AI, automation and data analysis.

JavaScript：ブロックの区切りは { }。メモ書きは // ではじめます。ウェブサイトの動きを作る言葉です。 JavaScript: blocks are marked out by { }, and notes begin with //. It is the language that makes websites move.

Luau：ブロックの終わりは end。メモ書きは -- ではじめます。Roblox のゲームを作る言葉です。 Luau: a block ends with end, and notes begin with --. It is the language for making Roblox games.

中身を入れて、名前を付けた収納ボックス。あとで名前を呼べば、中身が取り出せます。 A storage box with something inside and a name on it. Call the name later, and out comes the content.

片付けでいうと　「冬服」と書いたラベル付きの箱 In tidying terms: a box labelled “winter coat”

print(box)
let box = "冬服winter coat";

local box = "冬服winter coat"
print(box)

片付けでいうと　名札（文字）、個数（数）、片付け済みか（はい／いいえ） In tidying terms: a name tag (text), a count (number), and whether it has been tidied (yes / no)

D

条件（もし〜なら）Condition (if …)

状況によって、することを変えます。 Does one thing or another, depending on the situation.

片付けでいうと　もし冬物なら手前へ、そうでなければ奥へ In tidying terms: if it is winter wear, to the front; otherwise, to the back 

season = "冬winter"
if season == "冬winter":
    print("押入れの手前へPut it at the front")
else:
    print("奥へしまうStore it at the back")
const season = "冬winter";
if (season === "冬winter") {
  console.log("押入れの手前へPut it at the front");
} else {
  console.log("奥へしまうStore it at the back");
}
local season = "冬winter"
if season == "冬winter" then
  print("押入れの手前へPut it at the front")
else
  print("奥へしまうStore it at the back")
end

実行結果Result押入れの手前へPut it at the front

E

繰り返しLoop

同じことを、順番に何度もします。 Does the same thing over and over, in turn.

片付けでいうと　引き出しの中身を、1つずつ順番に出す In tidying terms: taking things out of the drawer, one at a time 

for item in drawer:
    print(item)
for (const item of drawer) {
  console.log(item);
}
for _, item in ipairs(drawer) do
  print(item)
end

実行結果Resultシャツ → 靴下 → 帽子shirt → socks → hat

F

関数Function

手順に名前を付けて、いつでも呼び出せるようにします。一度書けば、何度でも使えます。 Gives a procedure a name, so that it may be called at any time. Write it once; use it as often as you like.

片付けでいうと　「しまい方」の手順書。名前を呼ぶだけで実行できる In tidying terms: a written method for “putting away”, carried out simply by calling its name 

def put_away(item):
    print(item + "をしまった put away")

put_away("シャツshirt")
function putAway(item) {
  console.log(item + "をしまった put away");
}

putAway("シャツshirt");
local function putAway(item)
  print(item .. "をしまった put away")
end

putAway("シャツshirt")

実行結果Resultシャツをしまったshirt put away

4組み立て方How it is put together

どんなコードも、「入力 → 処理 → 出力」でできています。料理でいえば、材料 → 調理 → 料理です。 Every piece of code is built from input → processing → output. In cooking terms: ingredients → cooking → the dish.

ウェブサイトA website

入力（材料）INPUT (ingredients)ボタンを押すA button is pressed
処理（調理）PROCESSING (cooking)JavaScript が決めるJavaScript decides
出力（料理）OUTPUT (the dish)画面の表示が変わるThe display changes

AI の自動化AI automation

入力（材料）INPUT (ingredients)新しいメールが届くA new email arrives
処理（調理）PROCESSING (cooking)AI が要約するThe AI summarises it
出力（料理）OUTPUT (the dish)チャットに通知するA notice goes to the chat

ゲームA game

入力（材料）INPUT (ingredients)ジャンプボタンThe jump button
処理（調理）PROCESSING (cooking)キャラの高さを変えるThe character’s height changes
出力（料理）OUTPUT (the dish)キャラが跳ぶThe character leaps

作る順番は、片付けと同じThe order of work is the same as tidying

  1. 作りたいものを一文で言うSay what you wish to make in one sentence 例：「ボタンを押したら、今日の運勢が出る」For example: “press a button, and today’s fortune appears”.
  2. 入力・処理・出力に分けるDivide it into input, processing and output 材料、調理、料理の3つに分けます。Ingredients, cooking, dish: three parts.
  3. 小さな部屋に分けるDivide it into small rooms ひとつの関数に、ひとつの仕事だけを任せます。Give each function one job only.
  4. ひと部屋ずつ作って、そのつど動かすBuild one room at a time, and run it each time 全部作ってから試すより、少しずつ確かめるほうが迷いません。Checking little by little is less bewildering than testing everything at the end.
  5. エラーは「住所つきの伝言」An error is a message with an address 何行目で何が起きたかを教えてくれます。読めば直せます。It tells you what happened, and on which line. Read it, and you can mend it.
  6. 動いたら、片付けるWhen it works, tidy up 名前をわかりやすくして、同じ処理はひとつにまとめます。Give things clearer names, and merge any process that repeats.

5表と裏：どこで動く？Front and back: where does it run?

アプリやサービスは、お店のように「表」と「裏」に分かれて動きます。 Apps and services run rather like a shop, divided into a front and a back.

画面The screen フロントエンドFRONT END お客さんの手元で動きます。ブラウザやスマホの画面です。 Runs in the customer’s hands: the browser, or the phone screen. HTML, CSS, JavaScript, Swift, Kotlin
裏方The back room バックエンド（サーバー）BACK END (SERVER) お店の裏で、注文を受けて処理します。 Behind the shop, it takes the orders and deals with them. Python・JavaScript などPython, JavaScript and others
倉庫The warehouse データベースDATABASE 情報をしまっておく場所です。 The place where information is kept. SQL で出し入れしますPut in and taken out with SQL

AI の自動化は、多くが「裏方」で動きます。ほかのサービスや AI に頼むときは、「API」という注文窓口を使います。 AI automation mostly runs in the “back room”. To ask another service, or an AI, for something, you use an “API”, a sort of order window.

6用語ミニ辞典A small glossary

タップすると、意味が開きます。 Tap an entry to open its meaning.

API

お店の注文窓口です。決まった書き方で頼むと、答えが返ってきます。AI に仕事を頼むときにも使います。 The shop’s order window. Ask in the prescribed form, and an answer comes back. It is also how you ask an AI to do a job.

ライブラリLibrary

道具箱です。ほかの人が作った便利な部品を借りて、自分のコードで使えます。 A toolbox. You may borrow useful parts made by others and use them in your own code.

フレームワークFramework

建売住宅の骨組みです。基本の構造が最初からできているので、中身を作ることに集中できます。 A ready-built frame, like a house sold with its structure already in place, so that you can concentrate on what goes inside.

バグ・デバッグBugs and debugging

バグは、思いどおりに動かない不具合です。片付けでいえば「置き間違い」で、探して直すことをデバッグといいます。 A bug is a fault that stops things working as intended; in tidying terms, a misplaced item. Finding and mending it is called debugging.

実行（ラン）Run

書いた手順書のとおりに、コンピュータを動かすことです。 Making the computer carry out the written instructions.

ターミナルTerminal

文字だけでコンピュータに指示を出す窓口です。黒い画面に命令を打ち込みます。 A window for giving the computer instructions by text alone: you type commands onto a black screen.

Git

変更の履歴を残す記録帳です。片付ける前の写真をとっておくように、何度でも元の状態に戻せます。 A logbook of changes. Like a photograph taken before you tidy, it lets you return to an earlier state as often as you wish.
